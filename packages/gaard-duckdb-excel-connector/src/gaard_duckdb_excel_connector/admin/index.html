Excel File Loader

Loads local .xlsx workbooks as queryable datasource relations. Configure the datasource from the Datasources screen with a loader URL.

Uses DuckDB, MIT License.

Short form

Use this when automatic sheet mapping is enough. Every workbook sheet becomes a relation, and relation names are generated from sheet names. 

duckdb-excel:///C:/path/to/file.xlsx

The catalog is created automatically as dane.duckdb. If GAARD_DUCKDB_CATALOG_ROOT is set, the catalog is created there.

Explicit form

Use this when you want to choose the catalog path, relation names, loading mode, or type inference sampling. 

duckdb-excel:///C:/path/to/file.duckdb?workbook=C:/path/to/file.xlsx&sheet=Arkusz1:tabela1&sheet=Arkusz2:tabela2&mode=table
  • mode=table materializes sheets into tables.
  • mode=view reads the current workbook through views.
  • Use relation names such as tabela1 or magazyn in SQL.
Unix paths copied from a terminal sometimes escape spaces as \ , for example /srv/data/Sales\ 2026.xlsx. The loader accepts that form and normalizes it to a real space before validating the path.

URL builder

Materialized tables copy workbook data into the catalog. Live views read the current file on every query.
